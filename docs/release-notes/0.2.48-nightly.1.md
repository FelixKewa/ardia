## Fixed

- **A web page can no longer slip its own code into your content blocker.** A page could pose as the Hide Element
  picker and save a rule that ran its script on every site you visited. A saved rule must now be a plain one-line
  selector, and rules like that one are removed from your profile the next time Ardia opens it. Right-clicking inside
  a frame no longer offers to hide an element there; ⇧⌘H still does.
